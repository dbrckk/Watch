DOCUMENTATION

Utiliser Watch

Deux interfaces complémentaires : détection sur Android, analyse dans le navigateur.

01

Collecter sur Android

Installez Watch Fieldwatch (Android 10+), puis autorisez le Wi-Fi et le Bluetooth LE. Pour récupérer notre APK modifiée depuis Android : ouvrez le lien ci-dessous, choisissez la dernière exécution Android CI réussie, puis téléchargez fieldwatch-debug-apk dans Artifacts. Décompressez le ZIP et installez le fichier APK.

Important : cette APK de développement n'est pas signée pour une diffusion stable. Ne l'utilisez pas comme outil de sécurité critique ; les mises à jour peuvent nécessiter une réinstallation.

Télécharger un build Android Watch ↗
02

Partager vers Watch

Depuis Chrome Android, installez cette page web sur l'écran d'accueil. Dans la nouvelle APK Fieldwatch : Reports → Log export → Send observations to Watch web. Confirmez, puis choisissez Watch dans le menu de partage Android. Sinon, exportez un CSV/JSONL et utilisez Importer.

03

Analyser localement

Importez le ou les fichiers. Filtrez les observations, comparez les signaux RSSI, examinez les positions disponibles et exportez vos résultats.

04

Préserver la confidentialité

Les imports manuels restent en mémoire pendant la session. Les partages Android transitent temporairement par un cache privé du navigateur, supprimé dès la lecture ou écarté après expiration lors d'une activation ultérieure. Les identifiants MAC et les coordonnées sont masqués par défaut.

Limites importantes

Une page web ordinaire ne peut pas accéder librement aux scans Wi-Fi du système Android ni remplacer les services de scan natifs en arrière-plan. Les détections restent réalisées par Fieldwatch sur Android. Le partage nécessite une APK compilée depuis ce dépôt et une PWA installée avec Chrome Android. Certaines versions récentes de Chrome peuvent perdre la pièce jointe : l'import manuel reste possible.

Les identifications, catégories et éventuels signaux de proximité sont indicatifs : ils ne prouvent ni l'identité d'une personne ni la présence d'un dispositif de suivi. Utilisez cet outil uniquement dans un cadre légal et autorisé.

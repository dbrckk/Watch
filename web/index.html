INSTALLATION ET TRANSFERT

Utiliser Watch sur Android

Deux composants : l’APK effectue les relevés Wi-Fi/Bluetooth ; la console Web analyse leurs exports.

01 APPLICATION NATIVE

Installer Watch Fieldwatch

Android 10+ avec Wi-Fi et Bluetooth LE. Une version signée est à privilégier pour recevoir les mises à jour sans désinstaller l'application.

Voir les APK signées APK de test

Publication : aucune APK stable n'est présumée disponible. Vérifiez la page des releases avant d'installer. Pour l'APK de test : choisissez une exécution Android CI réussie, téléchargez l'artefact fieldwatch-debug-apk puis extrayez l'APK du ZIP. Une APK de test peut nécessiter une réinstallation et faire perdre ses données.

02 CONSOLE WEB

Installer la PWA Watch

Ouvrez ce site dans Chrome Android et utilisez ⋮ → Ajouter à l'écran d'accueil → Installer. Cela permet à Watch d'apparaître parmi les destinataires du partage Android lorsque le navigateur le prend en charge.

Installation manuelle possible depuis le menu de Chrome Android.

03 TRANSFERT À LA DEMANDE

Envoyer un relevé vers Watch

Dans l'APK Watch Fieldwatch, activez les journaux et scannez, puis ouvrez Reports → Log export → Send observations to Watch web. Confirmez et choisissez la PWA Watch installée dans la feuille de partage.

Le fichier est remis au navigateur localement, sans serveur Watch. Le transfert n'est pas continu et nécessite votre action.

Si Watch n'apparaît pas dans la feuille de partage, ou si Chrome perd la pièce jointe, exportez le journal en CSV/JSONL depuis l'APK et utilisez le bouton ci-dessus. Le partage direct nécessite encore une validation sur appareil réel.

PUBLICATION SIGNÉE PROPRIÉTAIRE DU DÉPÔT UNIQUEMENT

Activer les futures mises à jour Android

La première version signée exige une clé de publication privée persistante. Depuis Termux sur votre téléphone, exécutez les commandes suivantes. Ne partagez jamais la clé ni son mot de passe.

pkg update && pkg install gh openjdk-17 coreutils curl && gh auth login
curl -fL https://raw.githubusercontent.com/dbrckk/Watch/main/scripts/setup-watch-signing.sh -o setup-watch-signing.sh && bash setup-watch-signing.sh --publish

Le script demande le mot de passe localement, configure les secrets GitHub et exige de confirmer une sauvegarde séparée de la clé privée avant de lancer le workflow de publication. Lire le script avant exécution est recommandé. Il ne publie rien sans cette confirmation.

DOCUMENTATION

Utiliser Watch

Deux interfaces complémentaires : détection sur Android, analyse dans le navigateur.

01

Collecter sur Android

Installez Watch Fieldwatch (Android 10+), puis autorisez le Wi-Fi et le Bluetooth LE. Pour récupérer notre APK modifiée depuis Android : ouvrez le lien ci-dessous, choisissez la dernière exécution Android CI réussie, puis téléchargez fieldwatch-debug-apk dans Artifacts. Décompressez le ZIP et installez le fichier APK.

Important : cette APK de développement n'est pas signée pour une diffusion stable. Ne l'utilisez pas comme outil de sécurité critique ; les mises à jour peuvent nécessiter une réinstallation.

Versions Android signées (si disponibles) ↗ APK de test GitHub Actions ↗
02

Partager vers Watch

Depuis Chrome Android, installez cette page web sur l'écran d'accueil. Dans la nouvelle APK Fieldwatch : Reports → Log export → Send observations to Watch web. Confirmez, puis choisissez Watch dans le menu de partage Android. Sinon, exportez un CSV/JSONL et utilisez Importer.

03

Analyser localement

Importez le ou les fichiers. Filtrez les observations, comparez les signaux RSSI, examinez les positions disponibles et exportez vos résultats.

04

Préserver la confidentialité

Les imports manuels restent en mémoire pendant la session. Les partages Android transitent temporairement par un cache privé du navigateur, supprimé dès la lecture ou écarté après expiration lors d'une activation ultérieure. Les identifiants MAC et les coordonnées sont masqués par défaut.

Limites importantes

Une page web ordinaire ne peut pas accéder librement aux scans Wi-Fi du système Android ni remplacer les services de scan natifs en arrière-plan. Les détections restent réalisées par Fieldwatch sur Android. Le partage nécessite une APK compilée depuis ce dépôt et une PWA installée avec Chrome Android. Certaines versions récentes de Chrome peuvent perdre la pièce jointe : l'import manuel reste possible.

Les identifications, catégories et éventuels signaux de proximité sont indicatifs : ils ne prouvent ni l'identité d'une personne ni la présence d'un dispositif de suivi. Utilisez cet outil uniquement dans un cadre légal et autorisé.
